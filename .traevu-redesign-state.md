### Traevu Design Language

**Framework & stack**
- React 19 + TypeScript + Vite 7, plain hand-written CSS (no Tailwind), CSS custom properties.
- Theme engine in `src/theme.ts`: `data-theme`/`data-scheme`/`data-palette` attributes on
  `<html>`, localStorage persistence, system-mode via `prefers-color-scheme` media query,
  separate light and dark palette memory.

**Color system (semantic roles, all via CSS custom properties)**
- Surface ladder: `--page` (deepest, body/inset) → `--wall` (app bg) → `--surface`
  (chrome/panels/popovers) → `--content-bg` (main content pane).
- Ink ladder: `--foreground`, `--foreground-muted`, `--accent` (near-ink, used for active states).
- Interaction: `--tint` (≈3–5% ink) for resting controls, `--hover` (≈4.5–5.5% ink) for hover,
  `--fill`/`--onfill` for inverted primary fills, `--selection-*` for active/pressed fills.
- Lines: `--border` (hairline, 0.5px borders in use), `--ring` (slightly stronger hairline),
  `--line-3`, `--screen-edge`.
- Status accents used sparingly: `#58c68a` green (success/check dots), `#b43c3c`/`#e56d6d`
  danger, `#c8a866`/`#e8cd91` gold for PRO badges/featured plans.
- Full 5 light + 5 dark palettes (mono/sepia/azure/moss/mauve); every palette redefines the
  entire semantic set + syntax-highlight tokens (`--code-*`).

**Typography**
- Single family identity: `"JetBrains Mono"` for BOTH `--font-sans` and `--font-mono`
  (monospace-first voice), with UI/system fallbacks. Fragment Mono woff2 shipped for shader demos.
- Base 14px/22px body; scale: h1 26px/36px (−0.75px tracking), h2 20px/32px (−0.6px),
  h3 15px (−0.45px), body/controls 12px/20px, secondary 11px/16–19px, micro-labels 9–10px
  mono uppercase with 0.08em letter-spacing (e.g. `.toc-head`, footer nav labels, variant heads).
- Weight is restrained: 400 dominant, 450/500 only for emphasis; headings are weight 400 with
  negative letter-spacing. `font-variant-numeric: tabular-nums` on numeric values.

**Spacing, radius, border, shadow**
- Radii tokens: `--r-xs 4px, --r-sm 5px, --r-md 7px, --r-lg 9px, --r-xl 14px`,
  `--radius-base 0.275rem` for chips (×1.25). Cards/panels ≈ r-lg/r-md.
- Borders: 0.5px hairlines on nearly every control (`.search`, `.icon-btn`, `.code-card`,
  `.dialog`, `.control`, …); 1px only for structural separators.
- Shadows: layered realistic popover shadow `--popover-shadow` (6-stop, very soft) reserved for
  floating chrome; `--filled-button-shadow` (inset 0.5px ring + soft drop) only on active/filled
  controls. Dark mode: `--filled-button-shadow: none` — fills carry state alone.
- Elevation model: flat surfaces + border separation; depth only for popovers/dialogs/tooltips.

**Layout & shell patterns**
- Desktop app shell: CSS grid `260px sidebar + 1fr content`, full `100dvh`, sidebar tinted
  `--tint` over `--surface` with right hairline; content pane `--content-bg`.
- Sidebar: brand row (rotating −5° scale(1.04) hover brand mark), search button with `⌘K` kbd,
  sectioned nav (uppercase 11px labels, 1px hairline between sections), collapsible groups with
  chevron rotate 0→90° and `grid-template-rows 0fr→1fr` height animation, active link =
  inverted fill (`--fill`/`--onfill` + filled-button-shadow), variant-count chips, masked scroll
  area (gradient mask-image).
- Docs/content page: max-width column + sticky right rail (TOC with animated active line/dot
  gliding via `translate3d` + cubic-bezier(0.22, 1, 0.36, 1) 360ms), breadcrumb, `lede` muted
  intro, tag row of mono chips, step timelines (numbered circles + 1px connector), code cards
  with tabbar (active tab = 2px underline), copy-corner.
- Browse/catalog page: container-query responsive grid (4→3→2→1 cols), 16:9 media cards with
  hairline border that brightens on hover, staggered entrance animation
  (`browse-item-in` 360ms cubic-bezier(0.16,1,0.3,1), 35ms/index, capped 420ms), mono tag chips,
  filter pills with `aria-current` inverted fill, empty state pattern
  (`.browse-empty`: border-top hairline, muted copy + strong title), FAQ details/summary with
  rotating 45° plus icon, shared footer grid.
- Search dialog: centered modal over blurred scrim, 4-col thumbnail result grid, tooltips with
  arrow, grid collapses responsively.
- Popovers: anchored, `--surface` + popover-shadow; toast: bottom-center slide-up.
- Mobile: fixed topbar 44px, off-canvas sidebar `translateX(-100%)→0` with
  cubic-bezier(0.32, 0.72, 0, 1) 0.3s, scrim, breakpoints 1535/1199/1023/900/639/420.

**Controls & components**
- Buttons: quiet 32px actions (`--hover` bg on hover), icon buttons 28px with
  scale(1.06)/scale(0.94) press physics, segmented controls (theme switcher) with inverted
  active segment, pill choice controls (999px radius) with 2px inner padding.
- Inputs: 0.5px border + `--tint` background; focus = `box-shadow 0 0 0 2px color-mix(accent …)`
  and border color-mix toward foreground; placeholder = muted at ~66–70%.
- Custom slider: track with fill layer + knob, invisible native range input overlay,
  `ew-resize` cursor.
- Tags/chips: mono 8–11px, `--r-xs`/calc(radius-base×1.25) radii, tint backgrounds,
  hover translateY(-1px) lift.
- Tables: 0.5px row separators, th 16px/12px padding, td 12px, mono chips in cells.
- Progress/status: status-dot 6px circle, integrity card with 28px circular tinted icon well.
- Pricing cards: featured variant with gold-tinted border + radial-gradient corner glow
  (`radial-gradient(circle at 88% 4%, accent 18%, transparent)` over surface).
- Footer: 4-col grid (identity 1.75fr + 3 link cols), uppercase mono 9px column heads,
  hover translateX(2px) link shift, meta bar with hairline top.

**Motion & perceived performance**
- Signature easings: `cubic-bezier(0.16, 1, 0.3, 1)` (ease-out-expo feel) for entrances/stagger;
  `cubic-bezier(0.32, 0.72, 0, 1)` for sheets/drawer/brand rotate; 140–180ms for micro-hovers,
  260–360ms for gliding TOC/entrances.
- Stagger: index-based `animation-delay: min(calc(var(--i) * 35ms), 420ms)`.
- Micro-interactions: translateY(1px) on press, translateY(-1px) on lift-hover, brand rotate
  −5°/scale 1.04, chevron rotations, hover-reveal tools with opacity+translateY(2px)→0.
- Global `prefers-reduced-motion` kill-switch (0.001ms durations, no smooth scroll).
- Focus policy: `:focus-visible` = 2px outline color-mix(accent 68%, transparent), offset 2.
- Loading: skeleton-free "loading" placeholder states, hover-revealed tools (opacity), FPS meter
  overlay pattern, `content-visibility: auto` + `contain-intrinsic-size` for long grids.
- Selection color = color-mix(accent 35%, transparent); `color-scheme` set per theme.

**UX principles that make Traevu feel distinctive**
1. Monospace-first, editorial-technical voice: everything 11–14px, dense but calm.
2. Hairline-bordered flat surfaces with tiny radii — "engineered desk" aesthetic, no drop
   shadows except floating chrome.
3. Ink-inversion as the accent: active/selected states flip to solid foreground fill, not a hue.
4. Semantic token discipline: every color is a role, never a raw hex (outside status accents).
5. Layered neutral surface ladder creates hierarchy without color.
6. Restrained motion: fast micro-eases, one signature glide curve, reduced-motion respected.
7. Palettes as first-class feature: 2 schemes × 5 palettes, both scheme+palette remembered.
8. Detail micro-signals: variant counts, tabular numerals, uppercase tracked micro-labels,
   0.5px borders, masked scroll edges.
